iPhoneで独立アプリのように使う方法:
1. このフォルダの中身をHTTPS対応の静的サイトとして公開します（例: GitHub Pages）。
2. 公開したURLをiPhoneのSafariで開きます。
3. 共有ボタン →「ホーム画面に追加」→「追加」。
4. ホーム画面のアイコンから起動します。

注意:
- このZIPだけでは、まだホーム画面に追加できる公開URLにはなりません。
- GitHub Pagesなどへの公開作業が必要です。
- 自己採点式の試作です。自動採点はまだ厳密な同義語判定に対応していません。
